# Wayfare — 30-second ad

A Remotion project: 1920×1080, 30 fps, 900 frames. Everything in the frame is
drawn in code in Wayfare's "Folio" style (`mobile/shared/theme.ts`).

| Scene | What it shows | File |
| --- | --- | --- |
| 0–6 s | 3D travel scraps pull together into the mark (Three.js) | `src/scenes/Opening.tsx` |
| 5.5–11 s | The planner drafting the days | `src/scenes/Suggest.tsx` |
| 10.5–16 s | Manila → Tokyo on a 3D globe, into Day 2 on a real map | `src/scenes/MapScene.tsx` |
| 15.5–20 s | The Spend tab: pesos, yen, the daily allowance | `src/scenes/Budget.tsx` |
| 19.5–25 s | A side quest added in one tap, then a "leave in 12 min" alert | `src/scenes/SideQuest.tsx` |
| 25–30 s | End card | `src/scenes/EndCard.tsx` |

```bash
npm i
npm run dev                                     # Studio: scrub the ad, or each scene on its own timeline
npx remotion render WayfareAd out/wayfare-ad.mp4 # render (WebGL via ANGLE, set in remotion.config.ts)
```

Rendering needs a network connection: map tiles come from OpenFreeMap, photos
from Unsplash (`mobile/shared/images.ts`), fonts from Google Fonts and the sound
effects from remotion.media.

- `public/music.wav` is generated to the cut by `node scripts/music.mjs`. Replace
  the file to use a produced track instead.
- `src/data/land-dots.json` (the globe) is generated by `node scripts/land-dots.mjs`.
- Trip data is illustrative (the seeded Tokyo & Kyoto trip). The ad makes no
  claims about users, ratings or store availability.
